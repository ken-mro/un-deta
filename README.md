# うん、出た。（un-deta）

うんちが「出た」ことだけを、1タップで記録する大人向けの日記 PWA です。

公開先: https://ken-mro.github.io/un-deta/

## 概要

- 記録するのは「出た」だけ。出たときに1回押すだけで、出なかった日は何もしなくてかまいません（形状・量・色なども記録しません）
- 「前回の『出た』から N日」、月ごとのカレンダー、直近1年分のヒートマップを表示
- ビルド不要のバニラ HTML / CSS / JavaScript（ES Modules）。外部ライブラリ・CDN・Web フォントは使いません
- service worker により完全オフラインで動作。ダークモードは OS の設定に追従
- 本アプリは記録用のアプリです。医療機器ではなく、診断などを目的としません

## 使い方

1. ページを開き、**ホーム画面に追加**します（画面上部に iPhone / Android 別の手順が出ます）。ホーム画面に追加しないと、ブラウザが記録を自動で削除することがあります
2. 出たら、大きな **「出た」** を押します。出なかった日は何もしなくてかまいません。ホームには『前回の「出た」から N日』が表示されます。今日の記録は「今日の記録を取り消す」で未記録に戻せます
3. **「カレンダー」**で月ごとに「出た」日を確認できます（‹ › で前後の月へ。キーボードでは矢印キーで日付、PageUp / PageDown で月を移動）。過去の日は、**カレンダーの日付をタップ**すると修正・取り消しできます。「これまでの記録」（直近1年のヒートマップ）は見るだけの表示です
4. ときどき **「バックアップ」→「コピー」** で記録を短い文字列にして、メモなどに保存してください。同じ文字列を QR コードでも表示できます。最後のバックアップから30日たつと、アプリが声をかけます
5. 機種変更のときは、新しい端末でアプリをホーム画面に追加し、**ホーム画面のアプリの中で**文字列を「読み込む」に貼り付けます（上書き／統合を選べます）
   - iPhone・iPad では、Safari で開いたページとホーム画面のアプリで保存場所が別々です。QR コードを Safari で開いても、ホーム画面のアプリには反映されません

## プライバシー方針（要約）

- 記録は**端末のブラウザのストレージ（localStorage）の中だけ**に保存されます
- 運営者は個人情報・記録データを一切収集しません。アカウント登録もありません
- アナリティクス・広告・Cookie を使わず、記録を含む情報を外部へ送信しません（E2E テストで同一オリジン以外への通信がないことを確認しています）
- ホスティング事業者（GitHub）がアクセスログを取得する可能性があります

詳しくは [プライバシーポリシー](./privacy.html) と [利用規約](./terms.html) をご覧ください。

## ローカルで起動

Node.js 22 以上が必要です。

```bash
node scripts/serve.mjs
```

http://127.0.0.1:4173/ で開けます（`127.0.0.1` のみで待ち受けます）。GitHub Pages と同じサブパスで確認するときは:

```bash
node scripts/serve.mjs --base /un-deta/
```

http://127.0.0.1:4173/un-deta/ で開けます。

## テスト

開発用の依存は Playwright だけです。パッケージマネージャは pnpm を使います。

```bash
pnpm install
```

```bash
npx playwright install chromium webkit
```

```bash
npm test
```

```bash
npm run test:e2e
```

- `npm test` … ユニットテスト（`node --test`、`tests/unit/`）。日付計算・前回の「出た」からの日数・バックアップのエンコード・QR 生成などの純粋関数（`src/lib/`）
- `npm run test:e2e` … E2E テスト（Playwright、Chromium と WebKit の Mobile Safari、`tests/e2e/`）。オフライン動作・サブパス配信・アクセシビリティ・外部通信がないことなど
- `bash scripts/verify.sh` … 完成判定（必須ファイル、規約の必須項目、外部 URL の読み込み禁止、全テスト、PLAN の残タスク）

依存のセキュリティ対策として、`.npmrc`（インストールスクリプト無効化・バージョン固定）と `pnpm-workspace.yaml`（公開7日未満の版を使わない、registry 外の推移的依存を禁止 など）を設定しています。

アイコンを変更したときは、`icons/icon.svg`・`icons/icon-maskable.svg` を編集してから PNG を作り直します。

```bash
node scripts/build-icons.mjs
```

## GitHub Pages へのデプロイ

ビルドは不要です。リポジトリのファイルをそのまま公開します（パスはすべて相対なので、サブパス `/un-deta/` で動きます）。

1. 公開前に `HUMAN_TODO.md` の残り（規約の確認・実機確認など）を確認します
2. GitHub にリポジトリ `un-deta` を作成して push します
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存します
4. 数分後、https://ken-mro.github.io/un-deta/ で公開されます
5. アプリのファイルを更新したときは、`sw.js` の `VERSION` を上げてから push すると、利用者の端末のキャッシュが確実に更新されます

開発用のファイル（`tests/`、`scripts/`、`node_modules/` など）は公開されても動作に影響しませんが、`node_modules/` は `.gitignore` で除外しています。
