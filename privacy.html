プライバシーポリシー

ken_mro（以下「運営者」）は、記録アプリ「うん、出た。」（以下「本アプリ」）における情報の取り扱いを、次のとおり定めます。

1. 収集する情報

運営者は、本アプリを通じて、個人情報および記録データを一切収集しません。氏名・メールアドレスなどの入力やアカウント登録はなく、利用者が入力した記録（「出た」「ちょっと出た」の記録）も運営者に届くことはありません。

2. 記録の保存場所

  • 記録は、ご利用中の端末のブラウザのストレージ（localStorage）にのみ保存されます。運営者のサーバーやその他の外部に送信されることはありません。
  • オフラインで使えるよう、アプリ本体のファイル（画面やプログラム）を端末内のキャッシュに保存します。これに記録データは含まれません。
  • バックアップ文字列やQRコードは、利用者が自分でコピー・表示したときにだけ作られ、どこにも送信されません。保存先（メモアプリなど）での取り扱いは、利用者ご自身で管理してください。

3. アナリティクス・Cookie・外部送信

本アプリは、アクセス解析（アナリティクス）、広告、Cookie を使用しません。また、外部のフォントやライブラリなどを読み込まず、記録を含む情報を外部へ送信しません。

4. ホスティング事業者によるアクセスログ

本アプリは GitHub, Inc. が提供する GitHub Pages で公開しています。本アプリのページを読み込む際、GitHub が IP アドレスやアクセス日時などのアクセスログを取得する可能性があります。これは運営者が取得・閲覧するものではなく、GitHub のプライバシーポリシーに基づいて取り扱われます。詳しくは GitHub の一般プライバシー ステートメントをご覧ください。

5. 端末の変更・データの削除

  • 記録は端末ごとに保存されるため、機種変更をしても自動では引き継がれません。アプリ内の「バックアップ」で書き出した文字列を、新しい端末のアプリで読み込んでください。
  • iPhone・iPad では、Safari で開いたページとホーム画面に追加したアプリで保存場所が別になります。
  • ブラウザのサイトデータを削除する、ホーム画面のアプリを削除するなどの操作をすると、端末内の記録は削除され、運営者が復元することはできません。
